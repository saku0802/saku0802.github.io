# POKER LAB — NLH Live Cash Trainer (MVP 0.1)

スマホ・PC対応の静的Webアプリです。

## 収録機能
- ホームダッシュボード
- 13×13スターティングハンド表（UTG / MP / CO / BTN / SB / BB）
- 9人卓・6人卓のプリフロップ判断クイズ
- 回答数・正答率・連続正解・最近の回答をブラウザ内に保存
- PWA manifest / Service Worker（HTTPSで配信時）

## 使い方
公開ページをブラウザで開けば利用できます。進捗は利用したブラウザの localStorage に保存されます。

## 注意
初期レンジ表は学習用の概略分類で、GTOソルバー由来の厳密なレンジではありません。実際のレンジは人数、レーキ、スタック、オープンサイズ、店舗や相手の傾向に合わせて検証・調整してください。アプリはポーカーでの勝利や利益を保証しません。
